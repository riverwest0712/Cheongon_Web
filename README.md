# 청온 (Cheongon-Web)

### 청년들의 조건에 맞는 정책을 추천하는 청년 지원 웹 서비스

청온은 나이, 거주 지역, 소득, 재직 상태 등 개인 조건을 바탕으로 청년들에게 적합한 정책 정보를 제공하는 청년 지원 서비스입니다.

온통청년 정책 API를 활용하여 다양한 청년 정책 정보를 수집하고, 사용자 정보와 정책별 지원 조건을 비교하여 개인에게 적합한 정책을 추천하는 것을 목표로 합니다.

## 프로젝트 개요

| 항목 | 내용 |

| 개발 기간 | 2026.03 ~ 2026.07 |

| 플랫폼 | Web |
| 서버 | Node.js |
| 데이터베이스 | MySQL |

## 서비스 이용 흐름

```text
회원가입 및 로그인
       ↓
사용자 정보 입력
       ↓
청년 정책 데이터 조회
       ↓
사용자 조건과 정책 지원 조건 비교
       ↓
정책 추천 점수 산정
       ↓
맞춤 정책 추천 결과 및 상세 정보 확인
```

## 주요 기능

### 1. 청년 정책 데이터 관리
- 온통청년 정책 API를 통한 외부 정책 데이터 연동
- 정책별 지원 대상 및 신청 조건 데이터 수집
- 정책 정보의 데이터베이스 저장 및 관리
- 정책별 상세 정보 조회

### 2. 사용자 조건 기반 정책 추천
- 나이, 거주 지역, 소득, 재직 상태 등 사용자 정보 활용
- 사용자 조건과 정책별 지원 조건 비교
- 정책 지원 조건에 따른 추천 점수 산정
- 사용자 조건에 적합한 정책 추천 결과 제공

### 3. 데이터베이스 관리
- 사용자 및 정책 데이터 테이블 설계
- 정책 지원 조건을 관리하기 위한 테이블 구성
- 테이블 간 관계 설정 및 데이터 관리
- 정책 추천에 필요한 데이터 연동

## 프로젝트 개발 방향

- 사용자 조건에 따른 맞춤형 청년 정책 추천
- 외부 정책 데이터와 내부 데이터베이스의 연계
- 정책 지원 조건을 반영한 추천 로직 구성
- 사용자에게 필요한 청년 정책 정보를 효율적으로 제공

## 이용 안내

- 정책 추천 점수는 참고용 적합도이며, 실제 신청 자격 및 선정 여부는 해당 기관의 공식 공고를 확인해야 합니다.
- 정책 정보와 신청 일정은 변경될 수 있으므로 공식 기관의 최신 정보를 확인해야 합니다.
