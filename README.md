# 청온 (Cheongon-Web)

### 청년들에게 맞춤형 정책 정보를 제공하는 청년 지원 웹 서비스

청온은 청년들의 개인 조건을 바탕으로 신청 가능한 청년 정책을 탐색하고 추천하는 서비스입니다.

나이, 거주 지역, 소득, 재직 상태 등 사용자 정보를 정책별 지원 조건과 비교하여 개인에게 적합한 정책을 제공하는 것을 목표로 합니다.

## 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | 청온 (Cheongon) |
| 개발 기간 | 2026.07 ~ 2026.11 |

| 플랫폼 | Web |
| 데이터베이스 | MySQL |

## 주요 기능

### 1. 청년 정책 데이터 관리
- 청년 정책 데이터 수집 및 정리
- 정책별 지원 대상 및 신청 조건 관리
- 정책 정보를 데이터베이스에 저장하고 활용

### 2. 사용자 조건 기반 정책 추천
- 사용자 정보를 바탕으로 정책 지원 조건 비교
- 정책별 조건을 기준으로 적합도 및 추천 점수 산정
- 개인별 정책 추천 결과 제공

### 3. 외부 데이터 연동
- 온통청년 정책 API 연동
- 외부 정책 정보를 서비스 데이터와 연계
- 정책 데이터의 활용 및 관리
